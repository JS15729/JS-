## 修复个人中心表单提交 Bug（19:23）

**问题**：点击"保存修改"/"更新密码"按钮后页面消失/刷新，无法实际保存。

**根本原因**：`el-form` 内的 `el-button` 默认 `native-type="submit"`，触发了浏览器表单原生提交导致页面刷新。

**修复内容**（`client/src/views/ProfilePage.vue`）：
1. 两个 `el-form` 标签均加上 `@submit.prevent` 阻断原生提交
2. 所有操作按钮加 `native-type="button"` 明确声明为非提交按钮
3. `validate()` 改用 `try/catch` 替代 `.catch(() => false)` 写法，避免校验失败时继续执行
4. `changePw` 去掉 `ElMessageBox.alert`（会阻断 finally），改用 `setTimeout` 延迟 1.5s 跳转
5. `saveInfo` 响应数据兼容处理：`res?.data ?? res` 适配拦截器包装层
6. 新增 `resetPwForm()` 方法，附带 `clearValidate()` 清除校验状态
7. 移除未使用的 `ElMessageBox` import

**构建验证**：`vite build` ✅，ProfilePage chunk hash 已更新
